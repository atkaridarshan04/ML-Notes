# **Classification**  

- A **classification algorithm** is used to identify the category of new observations based on training data.  
- In classification, a program **learns** from the given dataset or observations and then classifies new observations into a number of classes or groups.  
- Example categories include:  
  - **Binary classification**: Yes or No, 0 or 1, Spam or Not Spam, Cat or Dog.  
  - **Multi-class classification**: Different types of crops, different genres of music.  

## **Types of Classification**  

### **1. Binary Classifier**  
- If the classification problem has **only two possible outcomes**, it is called a **Binary Classifier**.  
- **Examples**:  
  - Spam or Not Spam  
  - Cat or Dog  

### **2. Multi-class Classifier**  
- If a classification problem has **more than two possible outcomes**, it is called a **Multi-class Classifier**.  
- **Examples**:  
  - Classification of different types of crops  
  - Classification of different genres of music  

## **Types of Classification Algorithms**  

### **Non-linear Models**  
- K-Nearest Neighbors (KNN)  
- Support Vector Machines (SVM) (with kernel)  
- Naïve Bayes  
- Decision Tree Classification  
- Random Forest Classification  

### **Linear Models**  
- Logistic Regression  
- Support Vector Machines (SVM)  

### **Purely Classification Algorithms**  
- Logistic Regression  
- Naïve Bayes  

> **Note:** Some algorithms (e.g., Decision Trees, SVMs, Random Forest) work for both **classification and regression**.  

## **Evaluation Metrics**  
To assess the performance of classification models, we use the following metrics:  

- **Log Loss (Cross-Entropy Loss)**  
- **Confusion Matrix**  
- **AUC-ROC Curve**
